# 🌸 Women’s Conference – Desabrochar

A responsive landing page developed for the **III Women's Conference – Desabrochar**, hosted by **IEQ Casa do Pão**.

The website was created to provide event information and make the registration process simple and accessible for participants.

## ✨ Features

- Responsive design
- Event information
- Conference theme and Bible verse
- Full event schedule
- Registration form
- Clean and intuitive navigation
- Elegant and modern interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🎨 Design

The visual identity is inspired by the conference theme:

> **Winter Is Over**
>
> *"Arise, my darling, my beautiful one, come with me. See! The winter is past; the rains are over and gone. Flowers appear on the earth..."*
>
> **Song of Songs 2:10–13**

The design uses soft pink, cream, and white tones to represent renewal, hope, and spiritual growth.
